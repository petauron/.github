# Security Policy

Do not report security vulnerabilities through public issues.

Use GitHub Private Vulnerability Reporting or a GitHub Security Advisory for the affected
repository, where available. If a repository provides its own `SECURITY.md`, follow that policy
instead.

A security vulnerability is a weakness that could compromise confidentiality, integrity, or
availability. Ordinary defects, feature requests, and usage questions should be reported through
the normal GitHub issue process.

We do not commit to a fixed response time. Reports are reviewed according to their impact and the
information available.
