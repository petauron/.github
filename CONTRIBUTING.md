# Contributing

Thank you for contributing to Petauron projects.

## Before you start

- Search existing issues before opening a new one.
- For a large feature or a significant architectural change, open an issue first to discuss the
  approach.
- Follow any repository-specific contribution guidance. It takes precedence over this default.

## Contribution workflow

1. Fork the repository and create a focused branch from the current default branch.
2. Make a clear, limited change. A pull request should address one problem whenever practical.
3. Follow the repository's existing lint, formatting, and testing requirements.
4. Run the relevant tests before opening a pull request.
5. Describe what changed, why, and how it was tested in the pull request.

Keep the scope clear and avoid unrelated refactors or generated-file changes unless they are
necessary for the contribution.
